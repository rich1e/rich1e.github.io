# Dayfold 隐私政策

适用于 App Store 上架的 Dayfold（iOS 日记应用）。

## 一、我们收集哪些信息

**Dayfold 不设立账号系统，不收集可识别你个人身份的信息，也不含任何广告、分析或第三方追踪 SDK。**

你在 App 内创建的所有内容 —— 日记正文、标题、标签、情绪记录、照片、位置、天气快照、加密笔记本密码 —— 默认只保存在你的设备上。

## 二、数据存在哪里

### 1. 本机存储

- 日记、笔记本、标签、情绪记录、位置与天气快照：保存在设备本地的 Core Data 数据库中。
- 照片：由你主动选择后复制到 App 的本地目录。
- 加密笔记本：内容使用 AES-256-GCM 加密后落盘，密钥只保存在本机；App 不持有你的密码明文。

### 2. iCloud 同步（需你主动开启）

开启后，数据写入你**自己的 iCloud 私有数据库**（CloudKit 私有区）。该数据库归你的 Apple ID 所有，**开发者无法读取、检索或访问其中的内容**。关闭同步后，App 不再向 iCloud 读写数据；已同步的云端数据可在系统「设置 → Apple ID → iCloud → 管理账户存储」中删除。

未登录 iCloud 或未开启同步时，同步功能保持关闭，本地功能不受影响。

### 3. 天气数据

当日记需要记录天气时，App 会把当前经纬度发送给 **Apple WeatherKit** 以获取天气。该请求受 Apple 的隐私政策约束（<https://www.apple.com/legal/privacy/>）。App 只保存返回的天气快照，不额外上传你的身份信息。

### 4. 位置信息

仅在你授权「使用期间访问位置」后读取，用于给日记补充地点信息。位置只在本机使用并随日记保存；是否随 iCloud 同步取决于你是否开启同步。

### 5. 照片与相机

仅在你主动点击添加图片时访问相册或相机。所选图片复制到 App 本地目录，不会上传到开发者服务器。

### 6. Face ID / 密码

用于解锁加密笔记本或保护 App。生物特征由系统安全隔区处理，**App 无法读取你的指纹或面容数据**，只接收系统返回的「验证成功/失败」。

## 三、我们不做什么

- 不收集设备标识符用于广告或跨 App 追踪。
- 不使用第三方分析、崩溃上报或广告 SDK。
- 不建立用户画像，不向任何第三方出售或共享你的日记内容。
- 不在你不知情的情况下后台上传数据。

## 四、数据导出与删除

- **导出**：你可以使用 App 内的导出功能（单篇导出、备份）主动生成文件，文件由你自行保管。
- **删除单条/整本**：在 App 内删除后，本地立即移除；若开启同步，删除操作会同步到你的 iCloud 私有库。
- **清空全部数据**：App 内提供「清空本机数据」入口。卸载 App 会移除本机数据；iCloud 中的副本需在系统设置里删除。

## 五、儿童隐私

App 不面向 13 岁以下儿童单独提供服务，也不会有意收集儿童个人信息（本 App 本身不收集个人信息）。

## 六、政策变更

本政策更新后会修改文首的「生效日期」。若变更涉及数据处理方式的实质变化，会在 App 内或更新说明中提示。
